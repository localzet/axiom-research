# axiom-research v0.2.0

Двуязычный research-репозиторий с DOCX как основным форматом длинных документов. Основной пакет исследований
поставляется двумя полноценными антологиями: английской и русской. TeX/BibTeX-исходники намеренно отсутствуют в v0.2.

- `docx/Axiom-Research-Pack-v0.2.0-EN.docx`
- `docx/Axiom-Research-Pack-v0.2.0-RU.docx`
- `roadmap/Axiom-Roadmap-v0.2.0-EN.docx`
- `roadmap/Axiom-Roadmap-v0.2.0-RU.docx`

`PRIOR_ART.md` и `NOVELTY_BOUNDARY.md` фиксируют границу новизны; рядом лежат их русскоязычные варианты.
