# Граница новизны

Axiom намеренно объединяет уже существующие идеи: proof-carrying code, formal verification, SMT, CEGIS, capability
security, proof-carrying execution и zkVM. Исследовательская претензия **не** состоит в том, что каждый из этих
примитивов нов сам по себе.

Предлагаемый объект исследования — жизненный цикл ПО, в котором реализации являются заменяемыми, криптографически и
доказательно привязанными свидетелями устойчивого намерения/specification; эволюция направляется контрпримерами; а
доверие разделено между semantic proof и execution proof.
